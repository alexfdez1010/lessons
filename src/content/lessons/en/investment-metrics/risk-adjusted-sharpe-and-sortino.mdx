The same four annual returns can have a Sortino ratio of 2 or about 0.67 without a single return changing. Move the target from 0% to 1%, and both the return above target and the measured shortfalls change. A ratio only makes sense when you can reproduce what went into it.

You already know returns, volatility and drawdown. Sharpe, Sortino and Calmar relate a specified return measure to a specified risk measure. They describe selected data under conventions; none by itself establishes skill, future safety or suitability for a particular investor. The examples below are invented, use returns after a consistently defined set of costs and have no external deposits or withdrawals.

## Sharpe uses arithmetic excess returns and total variability

The **Sharpe ratio** divides mean return above a risk-free cash comparison by the standard deviation of those **excess returns**. A standard deviation measures dispersion around the mean; deviations above and below the mean both contribute.

For observation $t$, let $x_t=r_t-r_{f,t}$, where the portfolio and cash returns cover the same period. Our historical convention uses an arithmetic mean and **sample** standard deviation:

$$\bar{x}=\frac{1}{N}\sum_{t=1}^{N}x_t,\qquad s_x=\sqrt{\frac{\sum_{t=1}^{N}(x_t-\bar{x})^2}{N-1}}$$

$$\text{Sharpe}=\frac{\bar{x}}{s_x}$$

If the cash rate is constant across observations, subtracting it does not change the standard deviation, so $s_x=s_r$. With a varying cash return, calculate the excess-return series rather than assuming that shortcut.

### Worked four-year example

Take annual returns **−2%, +1%, +3%, +6%**, with a zero cash return in every year. The arithmetic mean is (−2 + 1 + 3 + 6) ÷ 4 = **2% a year**.

| Year | Annual return | Deviation from mean | Squared deviation in percentage points squared |
|---|---|---|---|
| 1 | −2% | −4 percentage points | 16 |
| 2 | +1% | −1 percentage point | 1 |
| 3 | +3% | +1 percentage point | 1 |
| 4 | +6% | +4 percentage points | 16 |
| Sum | — | 0 | **34** |

There are four observations, so the sample variance divides by **three**:

$$s_r=\sqrt{34/3}\approx3.36650\%$$

$$\text{Sharpe}=2\%/3.36650\%\approx0.59409$$

Dividing the squared deviations by four instead would give the **population-description** standard deviation $\sqrt{34/4}\approx2.91548\%$ and a ratio near **0.68599**. Both calculations can be described accurately, but they are different conventions. State the one used. Do not multiply by the square root of four merely because the dataset contains four years: the observations already have an annual frequency.

The race is a separate monthly illustration. Its method label specifies eleven returns, sample standard deviation, zero cash rate and the usual square-root annualization convention. Its identical total-return endpoints do not make the arithmetic monthly means identical.

### When to use it

Compare Sharpe over matched dates, return frequencies, currencies, cash baselines and cost treatments. A larger positive ratio means more measured excess return per unit of measured variability under those conventions. It does not capture all risk. With negative excess returns, blindly ranking ratios can favour a larger denominator; inspect return and variability separately. Universal labels such as “anything above two is excellent” hide the sample length and calculation method.

## Sortino uses the same target on both sides of the ratio

<MCQ client:visible pretest
  question="You change Sortino's annual target from zero to 1%. What must be recalculated?"
  options={[

    { text: 'Only the label next to the unchanged ratio' },
    { text: 'Only the risk-free return used by Sharpe' },
  ]}
  explanation="The target defines both the numerator and which observations fall short. Using a different target in the two places mixes incompatible quantities."

A **target return** is the threshold against which you assess shortfalls, sometimes called the **minimum acceptable return (MAR)**. It can be zero, a cash return or a stated goal. It must match the observation period. A positive return can still be a shortfall if it is below the chosen target.

In this lesson, historical **downside deviation** means the root mean square (RMS) of shortfalls below a fixed target $T$, using **all $N$ observations**:

$$D_T=\sqrt{\frac{1}{N}\sum_{t=1}^{N}\min(0,r_t-T)^2}$$

$$\text{Sortino}_T=\frac{\bar r-T}{D_T}$$

Returns at or above target contribute zero to the sum, but **remain in $N$**. This is not the standard deviation of only the losing returns, nor of the returns below their own average. The target is also subtracted in the numerator; it equals the Sharpe cash baseline only when you deliberately choose that same value. [CFA Institute, Deborah Kidd, on Sortino definitions and calculation variants](https://rpc.cfainstitute.org/-/media/documents/code/gips/the-sortino-ratio.pdf)

### Worked target of zero

Keep the annual series −2%, +1%, +3%, +6%, whose mean is 2%.

| Annual return | Shortfall below 0% | Squared shortfall in percentage points squared |
|---|---|---|
| −2% | 2 percentage points | 4 |
| +1% | 0 | 0 |
| +3% | 0 | 0 |
| +6% | 0 | 0 |

$$D_0=\sqrt{(4+0+0+0)/4}=1\%$$

$$\text{Sortino}_0=(2\%-0\%)/1\%=2$$

Dividing by the **one** below-target observation instead would give 2% downside RMS and a ratio of one. That is not our stated all-observation measure. Keeping the zero contributions in the average preserves information about how frequently shortfalls occurred.

<DownsideTargetRms client:visible />

### Worked target of one percent

At a **1% annual target**, the −2% return is short by **three percentage points**. The +1% return exactly meets the target and has zero shortfall. The other two returns also contribute zero:

$$D_{1\%}=\sqrt{(9+0+0+0)/4}=1.5\%$$

$$\text{Sortino}_{1\%}=(2\%-1\%)/1.5\%=2/3\approx0.66667$$

Both parts changed: the numerator fell from 2% to 1%, and downside RMS rose from 1% to 1.5%. The returns themselves stayed fixed. A denominator measured below 1% combined with a numerator above a different cash rate would not be this target-consistent Sortino.

### A larger Sortino does not prove mostly upside volatility

In this example, Sortino at target zero is **2**, much higher than the sample Sharpe of **0.59409** with cash zero. Yet the squared deviations **below the mean** total 16 + 1 = **17**, exactly the same as the 1 + 16 = **17 above the mean**. The sample is symmetric around its 2% mean.

Sharpe measures dispersion around that mean; downside RMS measures shortfalls below a separate threshold. Their denominators are not interchangeable pieces of one total-variance decomposition. Different targets, means and denominator conventions can create a large ratio gap. Inspect the actual return distribution before describing the source of its variability.

### When to use it

Use Sortino to ask how historical return above an explicit target compares with historical shortfalls from that target. Compare the same target, frequency, window and calculation convention across investments. A four-year series is a worked example, not a reliable estimate of every possible future shortfall. The CFA discussion also distinguishes historical discrete calculations from distribution-based approaches; reporting systems may use other arithmetic or geometric variants. Read their method rather than treating the name alone as a complete definition.

## Calmar combines compound growth with a historical drawdown

<MCQ client:visible pretest
  question="A reported maximum drawdown is 20% over the last four years. What does that establish?"
  options={[
    { text: 'The deepest observed decline in that measured window', correct: true },
    { text: 'The largest loss possible in every future year' },
    { text: 'The minimum loss guaranteed in the next decline' },
  ]}
  explanation="Historical maximum drawdown describes the selected observations. A future decline can be larger, and a coarser observation frequency can miss deeper declines between observations."
/>

For our convention, **Calmar** is annual compound growth divided by the positive magnitude of maximum drawdown over the same window:

$$\text{Calmar}=\frac{\text{CAGR}}{\lvert\text{historical maximum drawdown}\rvert}$$

Let $V_t$ be the total-return wealth index with no external flows. Its running peak is $H_t=\max_{s\le t}V_s$. The drawdown magnitude at a date is $1-V_t/H_t$, and the historical maximum is the largest of those values. Include the starting value in the running peak.

Calmar's numerator here is **CAGR**, not an arithmetic mean above a target. Its denominator is a peak-to-trough decline, not return dispersion or downside RMS. This compound-return definition matches the [Morningstar Calmar glossary](https://admainnew.morningstar.com/directhelp/Glossary/Custom_Statistics/Calmar_Ratio.htm). Specify the window and sampling frequency; do not assume every provider uses the same horizon or annualization convention.

### Worked wealth path and Calmar

Compound the same four annual returns, starting from 100:

| Date | Calculation | Wealth index | Running peak | Drawdown magnitude |
|---|---|---|---|---|
| Start | Initial value | 100.000000 | 100.000000 | 0% |
| Year 1 | 100 × 0.98 | 98.000000 | 100.000000 | 2% |
| Year 2 | 98 × 1.01 | 98.980000 | 100.000000 | 1.02% |
| Year 3 | 98.98 × 1.03 | 101.949400 | 101.949400 | 0% |
| Year 4 | 101.9494 × 1.06 | 108.066364 | 108.066364 | 0% |

The maximum **at these annual observation dates** is 2%. The four-year CAGR is:

$$\text{CAGR}=(108.066364/100)^{1/4}-1\approx1.95831\%$$

$$\text{Calmar}=1.95831\%/2\%\approx0.97916$$

Using the arithmetic mean of 2% would give one instead; it would not be the compound-numerator Calmar defined here. We have not observed intra-year prices, so the table cannot establish the maximum drawdown at a daily frequency.

### When to use it

Use Calmar to compare compound growth with the worst observed peak-to-trough decline over matched dates and sampling rules. It says nothing by itself about how long recovery took, future loss limits or whether a selected window omitted a crisis. A high Calmar built on a short calm sample can have a very small, unstable denominator.

## Check the denominator and the time basis before ranking

### Worked zero-denominator cases

| Observation pattern | Denominator | Result under these definitions |
|---|---|---|
| Every return equals 2%, cash is zero | Sample standard deviation = 0 | Sharpe has no finite defined value |
| Returns are 1%, 2%, 3%, target is zero | Downside RMS = 0 | Sortino has no finite defined value |
| The observed wealth index never falls | Maximum drawdown = 0 | Calmar has no finite defined value |

Changing just one return can turn a tiny denominator into a much larger one. The apparent precision of a large ratio can therefore exaggerate how much a short sample says. Report the denominator and observation count alongside the ratio.

### Match periods instead of mixing labels

The main example already uses **annual returns and annual targets**. For a separate monthly series, a 0.5% mean monthly excess return and 2% monthly standard deviation produce monthly Sharpe **0.25**. The usual square-root reporting convention gives $0.25\sqrt{12}\approx0.86603$ annually **under its no-serial-correlation assumptions**. It is not multiplication by the number of observations, and it is not a formula for the exact compounded annual return distribution.

Do not automatically apply that shortcut to Sortino. Converting a target and aggregating a sequence of shortfalls is not the same operation as scaling a standard deviation. If an annual target is a compounded growth goal, its equivalent monthly rate is $(1+T_{\text{annual}})^{1/12}-1$, but that conversion alone does not turn monthly downside RMS into annual downside RMS. State the actual reporting method and compare like with like.

### When to use it

Before comparing funds, record the sample dates, return frequency, currency, cost treatment, cash baseline, Sortino target, dispersion convention and handling of zero denominators. Use the three ratios as complementary descriptions alongside liquidity, leverage, tail scenarios and the underlying path. Their numeric rankings do not by themselves identify the cause of performance.
