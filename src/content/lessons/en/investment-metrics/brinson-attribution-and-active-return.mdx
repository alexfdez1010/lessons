Two reports describe the same portfolio and the same benchmark. One lists selection and interaction separately; the other puts them together. Their selection numbers differ even though the account earned exactly the same money. Before judging the manager, read the model.

**Performance attribution** is a structured reconciliation of a measured return difference. Brinson models organise it using category weights and category returns. They explain the arithmetic of a defined comparison; a positive labelled effect is not a causal estimate of skill or a promise about the next period.

This lesson builds on the course’s return, benchmark and cash-flow measurements. All holdings, returns and fees are invented. Each panel varies its own stated case. Until a section explicitly changes the assumptions, use one matched period, one currency, total simple returns including income, no fees, no external flows and no trading between categories during that period. Portfolios are long-only, fully invested and include every category, including cash when present.

## 1. A contribution is not the whole comparison

<MCQ client:visible pretest
 question={"Portfolio −2%, benchmark −5% in the same period. Which statement describes active return?"}
 options={[{"text": "It is +3 percentage points while the portfolio still lost money", "correct": true}, {"text": "It is a guaranteed 3% cash gain on the starting account"}, {"text": "It is −7 percentage points because both returns are negative"}, {"text": "It proves the manager caused positive alpha"}]}
 explanation={"Arithmetic active return subtracts the reference:−2−(−5)=+3 pp. It is not absolute profit or causal alpha."}
/>

A **weight** is a category’s opening value divided by the portfolio’s total opening value. A **category** is a common classification, such as an industry sector, applied to both portfolio and benchmark. A **benchmark** is the specified reference portfolio. Its category weights and returns are part of the model, not facts about the manager’s account.

Write $w_{Pi}$ and $w_{Bi}$ for portfolio and benchmark beginning weights in category $i$, and $r_{Pi}$ and $r_{Bi}$ for their category total returns. In our static, no-flow period,

$$
R_P=\sum_iw_{Pi}r_{Pi},\qquad R_B=\sum_iw_{Bi}r_{Bi},\qquad a=R_P-R_B.
$$

The product $w_{Pi}r_{Pi}$ is a **contribution to portfolio return**. The arithmetic active return $a$ subtracts the benchmark’s total return. Return levels use percentages; differences between those levels use **percentage points (pp)**.

Portfolio return is $0.8(12\%)+0.2(-2\%)=9.6\%-0.4\%=9.2\%$. Benchmark return is $0.6(10\%)+0.4(0\%)=6\%$. Active return is $9.2\%-6\%=3.2$ pp.

With USD 10,000 opening capital, A earns $8000(0.12)=960$ dollars and B loses $2000(0.02)=40$. Portfolio terminal wealth is 10,920; the reference portfolio reaches 10,600. The difference is USD 320, or 3.2% of the common starting capital.

The raw category contribution differences are $9.6-6=3.6$ pp in A and $-0.4-0=-0.4$ pp in B. Those sum to 3.2, but do not yet separate weight choices from category-return differences.

Use the **beginning** weights for this identity. A’s ending weight would be $8960/10920\approx82.051282\%$. Substituting it into the beginning-weight calculation produces about 9.487179%, not the actual 9.2%. Different dates answer different questions.

### When to use this comparison

First define the benchmark, category mapping, dates, currency, income and fee basis. A portfolio can outperform while losing money: −2% versus −5% is +3 pp active return. Active return is also distinct from the [model-relative alpha comparison](/investment-metrics/market-alpha-and-beta); Brinson does not perform that risk adjustment.

## 2. Allocation asks where the weight sat

<MCQ client:visible pretest
 question={"A category rose 6%, and you overweighted it. Must BF allocation be positive?"}
 options={[{"text": "No; compare its benchmark category return with the whole benchmark return", "correct": true}, {"text": "Yes; every positive category return gives positive BF allocation"}, {"text": "No; BF ignores weights entirely"}, {"text": "Yes; positive allocation is the same as guaranteed future skill"}]}
 explanation={"BF uses active weight times the category benchmark return minus the total benchmark return. A positive absolute return can still lag that reference."}
/>

Imagine allocating seats between two performances before seeing the reviews. To isolate the category-weight comparison, temporarily use each category’s **benchmark** return rather than the portfolio’s own category return.

In the **Brinson–Fachler (BF)** allocation convention,

$$
A_i=(w_{Pi}-w_{Bi})(r_{Bi}-R_B).
$$

The first difference is the **active weight**. The second says whether the category’s benchmark return exceeded the whole benchmark. Both are signed. Using our opening case:

- A: $(0.8-0.6)(0.10-0.06)=0.2(0.04)=0.008$, or **+0.8 pp**.
- B: $(0.2-0.4)(0-0.06)=(-0.2)(-0.06)=0.012$, or **+1.2 pp**.

Total allocation is $0.8+1.2=2$ pp. Overweight A and underweight B both contribute positively **relative to this benchmark’s category returns**. The effect does not use A’s portfolio return of 12%.

<BrinsonAttributionLab client:visible mode="allocation" title="BF allocation compares benchmark category returns" caption="Invented BF allocation: active category weight times category benchmark return minus total benchmark return. Benchmark 60/40% earns 10/0%, total 6%. Initial portfolio 80/20%; only its weight changes here. Category portfolio returns do not enter the allocation formula. Effects are percentage points, not causal effects or forecasts." />

A positive category market return is not enough. In a separate example, an overweight of 0.1 in a category that earns 6% while the whole benchmark earns 8% gives $0.1(0.06-0.08)=-0.002$, or −0.2 pp allocation. “It went up” and “it helped relative to the reference” are different statements.

### When to inspect allocation

Use it to discuss the weight comparison under the stated benchmark and category definitions. It is an ex-post model term, not a stand-alone investable return or evidence that the allocation was causally skilful. A changed benchmark can change the attribution story without changing the portfolio’s dollars.

## 3. Selection holds benchmark weights fixed

<MCQ client:visible pretest
 question={"In the three-effect convention, which weight determines pure selection?"}
 options={[{"text": "The category benchmark weight multiplies its portfolio-minus-benchmark return", "correct": true}, {"text": "The portfolio weight always replaces every benchmark weight"}, {"text": "The ending category weight determines the opening-period formula"}, {"text": "Weights disappear because selection is a category percentage return"}]}
 explanation={"Pure S_i=w_Bi(r_Pi−r_Bi). Adding interaction changes the coefficient to the portfolio weight."}
/>

Now keep the **benchmark weights** and replace benchmark category returns with portfolio category returns. This isolates a different comparison:

$$
S_i=w_{Bi}(r_{Pi}-r_{Bi}).
$$

For A, $0.6(0.12-0.10)=0.012$, or **+1.2 pp**. For B, $0.4(-0.02-0)=-0.008$, or **−0.8 pp**. Total benchmark-weighted selection is only $1.2-0.8=0.4$ pp.

<BrinsonAttributionLab client:visible mode="selection" title="Selection with benchmark weights" caption="Invented benchmark-weighted selection uses weights 60/40%, benchmark returns 10/0% and initially portfolio returns 12/−2%. The return controls change only this panel. Pure selection holds benchmark weights; it is not the entire realised category return, nor a manager-skill probability." />

Selection is a contribution under a convention, not A’s entire 12% category return. Nor does a positive absolute return guarantee positive selection. Try a portfolio A return of 6% against the same category benchmark of 10%: A’s selection becomes $0.6(0.06-0.10)=-0.024$, or −2.4 pp, even though its holdings made money.

Notice which weight appears in the formula. Changing only the portfolio’s A weight does not change this **benchmark-weighted** selection number. The actual portfolio still changes; the remaining interaction term will account for the extra weight on the category-return difference.

### When to inspect selection

Use it to describe within-category return differences under a common classification. It can reflect style exposures, the instruments held, costs, chance and the period chosen. The label “selection” alone does not distinguish those explanations or identify persistent manager skill.

## 4. Interaction keeps the two replacements from losing a term

<MCQ client:visible pretest
 question={"An underweighted category has portfolio return −2% versus reference 0%. Can its interaction be positive?"}
 options={[{"text": "Yes; negative active weight times negative category-return difference is positive", "correct": true}, {"text": "No; every effect must share the category return’s sign"}, {"text": "Yes; this turns its negative return into positive absolute stock profit"}, {"text": "No; interaction is always zero for an underweight"}]}
 explanation={"The cross-product can be positive although the benchmark-weighted selection is negative. The labels describe different terms."}
/>

Changing weights and category returns together creates a product of differences. Leaving it out is like expanding $(x+u)(y+v)$ and forgetting $uv$:

$$
I_i=(w_{Pi}-w_{Bi})(r_{Pi}-r_{Bi}).
$$

For A, $0.2(0.12-0.10)=0.004$, or **+0.4 pp**. For B, $(-0.2)(-0.02-0)=0.004$, also **+0.4 pp**. Total interaction is 0.8 pp.

The B result is a useful sign check: portfolio B underperformed its category reference, so its selection was negative. Holding **less** of that underperforming category makes the cross-product positive. It does not turn B’s −2% return into evidence of good stock picking.

<BrinsonAttributionLab client:visible mode="interaction" title="Interaction completes the two-replacement identity" caption="Invented interaction is active weight times category-return difference. Initial portfolio 80/20%, benchmark 60/40%, portfolio returns 12/−2%, benchmark 10/0%. Change portfolio A weight or A return; B portfolio return stays −2%. A positive cross-product can accompany negative pure selection when an underperforming category is underweighted." />

Using decimal return fractions, the complete BF reconciliation is now

$$
\sum_i(A_i+S_i+I_i)=0.02+0.004+0.008=0.032=3.2\text{ pp}=R_P-R_B.
$$

Why does it work? Since both complete weight lists sum to one, $\sum_i(w_{Pi}-w_{Bi})=0$. Consequently allocation sums to $\sum_i(w_{Pi}-w_{Bi})r_{Bi}$. Selection plus interaction sums to $\sum_iw_{Pi}(r_{Pi}-r_{Bi})$. Add those expressions: the mixed benchmark terms cancel, leaving $R_P-R_B$.

This is a **total-portfolio** identity. Under BF, the attributed category totals are A $0.8+1.2+0.4=2.4$ pp and B $1.2-0.8+0.4=0.8$ pp. They differ from the raw contribution differences 3.6 and −0.4 pp above. BF subtracts $(w_{Pi}-w_{Bi})R_B$ within each category; those adjustments cancel across the complete portfolio, not within each category.

### When to retain or combine interaction

Retain it when the report presents three separate effects. If another convention combines it with selection, use that definition explicitly. Interaction is an algebraic term, not another cash payment. Reconciliation is a necessary check of a report, not a causal explanation of how much value the manager would create under an alternative action.

## 5. A convention changes the explanation, not the account

<MCQ client:visible pretest
 question={"A report changes selection from 0.4 pp to 1.2 pp without changing any holdings or returns. What could explain it?"}
 options={[{"text": "It combined the original 0.8 pp interaction with selection", "correct": true}, {"text": "It necessarily created another 0.8 pp of cash profit"}, {"text": "It proved that every category benchmark changed"}, {"text": "It converted a one-period residual into a persistent alpha estimate"}]}
 explanation={"Report conventions can move effects between columns. The account and total active return need not change."}
/>

The [CFA Institute Research Foundation’s attribution review](https://rpc.cfainstitute.org/sites/default/files/-/media/documents/book/rf-lit-review/2019/rflr-performance-attribution.pdf) distinguishes BF allocation from the variant commonly associated with **Brinson–Hood–Beebower (BHB)**:

$$
A_i^{\rm BHB}=(w_{Pi}-w_{Bi})r_{Bi}.
$$

There is no subtraction of the whole benchmark return. Our A allocation becomes $0.2(0.10)=2$ pp and B becomes $(-0.2)(0)=0$. Their aggregate is still 2 pp because the complete active weights sum to zero. The category-level stories differ.

Another report may fold interaction into selection:

$$
S_i+I_i=[w_{Bi}+(w_{Pi}-w_{Bi})](r_{Pi}-r_{Bi})=w_{Pi}(r_{Pi}-r_{Bi}).
$$

That gives A $0.8(0.02)=1.6$ pp and B $0.2(-0.02)=-0.4$ pp: combined selection **1.2 pp**, not the separate selection figure 0.4 pp. The additional 0.8 was not new profit; it moved between report headings.

Under the BHB-associated three-effect convention, A’s attributed category total is $2+1.2+0.4=3.6$ pp and B’s is −0.4 pp, matching the raw contribution differences. Under BF, they were 2.4 and 0.8 pp. Both aggregate reconciliations use the same actual portfolio and benchmark returns.

### When to compare attribution reports

Read formulas and treatment of interaction, not just column names. Also check category classification, benchmark composition, return method, dates and costs. “Selection increased from 0.4 to 1.2” need not describe a performance improvement; it may describe a changed reporting convention. None of these Brinson variants is the regression alpha taught earlier.

## 6. Cash and fees must reconcile too

Zero-return cash can have a nonzero **relative allocation effect**. Consider a separate opening portfolio: 80% A, 10% B and 10% cash. Benchmark weights remain 60% A, 40% B and zero cash. Keep the category returns above and stipulate cash total return zero in both comparisons.

Portfolio gross return is $0.8(0.12)+0.1(-0.02)+0.1(0)=0.094$, or 9.4%; benchmark return is still 6%. Gross active return is **3.4 pp**.

Cash allocation is $(0.1-0)(0-0.06)=-0.006$, or **−0.6 pp**. Omitting that row leaves a subtotal of $2.4+1.6=4$ pp, which does not reconcile to the actual 3.4 pp. The two remaining portfolio weights sum to 90%, not 100%. Silently normalising them would describe a different portfolio.

Now charge a separate **20-basis-point fee on initial capital at period end**, outside the supplied gross category returns. On USD 10,000 that is USD 20, a return contribution of −0.2 pp. Net portfolio return is $9.4\%-0.2\%=9.2\%$; active return versus the stipulated no-fee benchmark is $3.4-0.2=3.2$ pp.

Comparing the two stipulated gross accounts, replacing ten percentage points of B with cash increases return from 9.2% to 9.4%. The BF cash row of −0.6 pp is not that account-to-account difference: other category effects change too.

The 0.2 pp gross improvement between these accounts and the separate 0.2 pp fee happen to offset in this example. That coincidence does not make either omission valid. If the category returns already include the same fee, do not subtract it again. A fee on closing assets, a different date or a different cost allocation would need its own calculation.

### When to investigate a residual

Check missing categories, weight totals, fees, currency translation, flow treatment, rounding and category mapping before calling a residual “selection”. Our cash reference of zero is explicitly supplied; an absent category in an arbitrary benchmark does not automatically have a known zero return. Holdings-based models need a documented mapping and return convention for such cases. Derivatives, shorts or unaccounted transfers require a model that represents their exposures; do not force them into this long-only example by discarding weights.

## 7. A flow can change the holdings used for attribution

<MCQ client:visible pretest
 question={"TWR removes the mechanical effect of a contribution. Does it also remove the effect of investing that contribution in a different mix?"}

This is a **separate two-subperiod account** for flow mechanics, not the earlier period’s portfolio or benchmark. Begin with USD 100: 50 stock and 50 cash. The stock earns 10% in each half and cash earns zero. At the midpoint, contribute USD 100 and invest it entirely in stock.

The first portfolio return is $105/100-1=5\%$. The second is $220.5/205-1\approx7.560976\%$. With valuations around the flow, exact TWR is

$$
(1.05)\left(\frac{220.5}{205}\right)-1\approx12.939024\%.
$$

The original stock weight 50% times the full stock return $1.1^2-1=21\%$ would give 10.5%. It no longer represents the changed exposure: after the contribution, stock weight is $155/205\approx75.609756\%$. A single static beginning-weight attribution is not the right representation of the whole window.

<BrinsonAttributionLab client:visible mode="flows" title="A contribution changes value and may change exposure" caption="Separate two-halfperiod account, initial stock 50 USD/cash 50 USD, stock gains 10% each half and cash 0%. TWR removed the contribution’s mechanical wealth jump; it did not remove the effect of choosing more stock exposure. Change only the contribution’s destination to the pre-flow proportions $55/105$ stock and $50/105$ cash. Holdings then scale proportionally, the second-period portfolio return is $5.238095\%$, and linked TWR is 10.5%, matching the no-flow buy-and-hold case. The amount contributed is the same; the allocation policy differs.

Dollar gain is $220.5-100-100=20.5$ in the all-stock case, not a return definition by itself. Do not replace exact TWR with that gain divided by initial value or assume a Modified Dietz estimate is identical. Those measures answer the cash-flow questions developed in the previous lessons.

### When to split the window

Use meaningful subperiods and contemporaneous weights/valuations when flows or rebalancing alter the exposure. Measure the portfolio and its stated benchmark consistently, compute each period’s attribution under its declared model, then link it with an explicit rule. The [GIPS handbook](https://www.gipsstandards.org/standards/gips-standards-for-firms/gips-standards-handbook-for-firms/) describes valuation around flows and geometric linking for true TWR within that reporting framework. A return-measurement convention does not itself prove who controlled the flow or made a skilful decision.

Period 1 portfolio return is $0.6(0.14)+0.4(0.04)=10\%$ and benchmark return is 8%. Its BF effects are allocation +0.8 pp, selection +1 pp and interaction +0.2 pp. In period 2, portfolio return is $0.75(-0.12)+0.25(-0.04)=-10\%$ and benchmark return is −8%. Category returns now match, so selection and interaction are zero; allocation is −2 pp.

Compounded portfolio return is $1.10(0.90)-1=-1\%$. Benchmark return is $1.08(0.92)-1=-0.64\%$. Their difference is **−0.36 pp**. Adding period active returns gives $2-2=0$ pp; multiplying $1.02(0.98)-1$ gives −0.04%. Neither equals the intended difference of compounded returns.

### One explicit wealth identity

Let $a_t=R_{Pt}-R_{Bt}$. Expanding the two compounded wealth factors gives the exact identity

$$
R_P^{\rm cum}-R_B^{\rm cum}=a_1(1+R_{B2})+a_2(1+R_{P1}).
$$

Use that identity’s multiplier 0.92 on **every** period-1 effect and 1.10 on **every** period-2 effect:

- Allocation: $0.8(0.92)+(-2)(1.10)=-1.464$ pp.
- Selection: $1(0.92)+0(1.10)=0.92$ pp.
- Interaction: $0.2(0.92)+0(1.10)=0.184$ pp.

Their sum is $-1.464+0.92+0.184=-0.36$ pp. This is the declared decomposition in the panel’s initial setting.

Another exact expansion uses $a_1(1+R_{P2})+a_2(1+R_{B1})$. Its multipliers are 0.90 and 1.08. Applying them consistently gives allocation −1.44 pp, selection +0.90 pp and interaction +0.18 pp: the **same total**, different assignments to effects.

Exact reconciliation alone does not select a universal production linking method. The [CFA attribution review](https://rpc.cfainstitute.org/sites/default/files/-/media/documents/book/rf-lit-review/2019/rflr-performance-attribution.pdf) discusses linking and smoothing choices, while [Menchero’s article abstract](https://rpc.cfainstitute.org/research/financial-analysts-journal/2004/multiperiod-arithmetic-attribution) highlights additional desirable properties. Our two expansions teach the accounting issue; they are not causal attributions or a blanket recommendation of one method.

### A different denominator gives a different measure

Relative terminal-wealth performance is

$$
\frac{1+R_P^{\rm cum}}{1+R_B^{\rm cum}}-1=\frac{0.99}{0.9936}-1\approx-0.362319\%.
$$

This divides the wealth difference by final benchmark wealth. The arithmetic difference −0.36 pp corresponds to dividing excess wealth by common starting wealth. Some reports call the ratio measure geometric active or geometric excess return; read that definition explicitly. It is not interchangeable with the arithmetic active difference. If benchmark terminal wealth is zero, the ratio is undefined even though an arithmetic return difference may still exist.

### When to read a multiyear report

Identify the target measure, period model and linking rule. Check reconciliation at category, period and whole-window levels. A well-balanced attribution account can clarify a historical comparison; it does not estimate what alternative actions would have caused or establish future skill.
