A weather forecast can help you choose an umbrella without causing rain. A financial feature can similarly help predict a return without causing the asset to move. A different question arises when you ask whether changing your order's routing would change its execution cost.

This course needs both questions, stated carefully. We will distinguish **prediction**, **performance relative to a benchmark model**, and **the causal effect of a specified action**. Observational data can inform all three, but the assumptions and outcomes differ. A good backtest is useful evidence for a trading decision; it does not automatically identify an effect of intervening on its predictor.

Every numerical population below is invented. The structural equations and potential outcomes are supplied as classroom assumptions. In an empirical study, those assumptions would have to be justified rather than read from a table.

## A useful predictor need not cause the underlying return

<MCQ client:visible pretest

 explanation={"Changing portfolio exposure and changing the cause of the asset return are different questions. Prediction can inform a decision under explicit implementation assumptions."}

A **predictive association** relates information available now to a later outcome. A **causal effect** compares outcomes under specified alternative actions. [Hernán, Hsu and Healy](https://arxiv.org/abs/1804.10846) distinguish description, prediction and counterfactual prediction. Using the same regression software does not make the questions interchangeable.

### A fully specified common-cause example

At the start of a period, regime $Z$ and independent feature noise $U$ each take −1 or +1 with equal probability. The trader observes $X=Z+U$ before choosing a position. An independent return shock $E$ takes −0.04 or +0.04 only at the end of the period. The underlying simple return is $Y=0.02Z+E$. Changing the recorded feature alone changes neither the regime nor the return equation. The four rows below are conditional means over the two possible shocks, not four deterministic returns.

The population means of X and Y are zero. Independence gives $\mathbb E[Z^2]=1$, $\mathbb E[UZ]=0$ and zero cross terms with E:

$$
\operatorname{Cov}(X,Y)=\mathbb E[(Z+U)(0.02Z+E)]=0.02,
\qquad \operatorname{Var}(X)=1+1=2.
$$

The population regression slope is $0.02/2=0.01$ return per feature unit, or **one percentage point per unit of X**. Correlation is instead dimensionless:

$$
\operatorname{Var}(Y)=0.02^2+0.04^2=0.002,\qquad\operatorname{Corr}(X,Y)=\frac{0.02}{\sqrt2\sqrt{0.002}}=\frac1{\sqrt{10}}\approx0.31622777.
$$

A correlation coefficient is not numerically the same object as a causal return difference or a regression slope. Their units and comparisons differ.

Among observed episodes with $X=+2$, mean return is +2%; with $X=-2$, it is −2%. That conditional contrast is four percentage points. But forcing the recorded X to either value while leaving the stated generating equations intact does not alter Y: its causal effect on the underlying return is zero. We know this because the model supplies the equations, not because a scatterplot alone proves the missing causal arrow.

### The position rule is another object

Now take a **price-taking** position $w=X/2$: −1, 0 or +1 times starting capital in the asset. Unused cash earns zero; fractional positions and shorting are assumed feasible. We exclude feedback from this small trader to asset returns. Gross one-period portfolio return is $wY$.

The four conditional mean portfolio returns are 2%, 0%, 0%, 2%, averaging **1% gross**. There are eight actual joint outcomes once the two end shocks are included, each with probability 1/8 in this initial balanced case. For example, X=+2 gives w=1 but actual Y is −2% or +6%: the position can lose.

Close the position at period end. Assume an invented total entry-and-exit charge $c=0.001|w|$ of starting capital, assessed by the close using the initial absolute position. It is ten basis points per unit of $|w|$ for the whole period, not ten points on each leg or a fee on changing turnover. Since average $|w|$ is $1/2$, expected total period cost is five basis points of capital. Expected net portfolio return is **0.95%**, with losing outcomes possible. This is a population expectation under the model, not a return guarantee.

The rule uses X as information. It does not require X to cause Y. Selecting the asset exposure changes the portfolio's cash flows; that is different from forcing the feature to cause an underlying price rise. In the visual, forcing every recorded X to +2 breaks its informational relationship with Z. The resulting constant long position has zero expected underlying return and pays the stipulated ten-basis-point charge. The feature edit has not manufactured an asset return.

### When to use it

Write the predictor, action and outcome separately. For a small price-taking strategy, useful conditional return predictions, feasible positions, costs and risk can support a decision without a causal effect of the predictor on the asset. For a large order that changes prices, the price-taking assumption fails and the policy's feedback needs a model.

## Alpha is relative to a performance model

<MCQ client:visible pretest

In trading conversation, “alpha” sometimes means a signal or any expected edge. A performance **regression alpha** has a more specific meaning: an intercept relative to chosen benchmark factors, return definitions and sampling periods. It is not synonymous with correlation, a causal effect or demonstrated skill.

Take aligned one-year simple returns in the same currency: portfolio 12%, market 10%, risk-free return 2%, and **specified beta 1.5**. For an ex-post comparison, use the given realised market return in a CAPM-style benchmark:

$$
b=2\%+1.5(10\%-2\%)=14\%.
$$

The portfolio beat the market but fell below this supplied risk-adjusted benchmark. The number −2 is a **one-period realised abnormal return**. It is not an estimate of a persistent alpha from one observation. The [CFA Institute's CAPM reading](https://www.cfainstitute.org/insights/professional-learning/refresher-readings/2026/portfolio-risk-return-part-2) gives the expected-return model under its assumptions; inserting realised market returns here is an ex-post benchmark calculation, not a forecast or proof that the model is true.

### An estimated intercept needs uncertainty

Over many aligned periods, one model is

$$
R_{p,t}-R_{f,t}=\alpha+\beta(R_{m,t}-R_{f,t})+\varepsilon_t.
$$

The intercept alpha and the slope beta are estimated, with residual noise. A one-period abnormal return can contain both alpha and the residual. Change the factor model, estimation window, currency, fee treatment or timing and the reported alpha can change. [CFA's Manager Selection](https://rpc.cfainstitute.org/sites/default/files/-/media/documents/book/rf-publication/2013/rf-v2013-n4-1-pdf.pdf) discusses the regression interpretation and the difficulty of separating persistent performance from noise and selection.

For a **separate invented monthly fit**, suppose estimated alpha is 0.20 percentage points per month and its assumed standard error is 0.30 points. Under an appropriate normal approximation for this estimator,

$$
\widehat\alpha\pm1.96\operatorname{SE}=0.20\pm0.588=[-0.388,0.788]\text{ percentage points per month}.
$$

The estimate divided by its standard error is $0.20/0.30\approx0.6667$. The interval includes zero. It is not a 95% probability that this fixed alpha is inside the realised interval, and it does not capture every model-selection, dependence or implementation error. Those would require additional analysis; see [hypothesis testing](/statistics-for-finance/hypothesis-testing-and-significance).

### When to use it

Before interpreting “positive alpha”, name the model, horizon, sample, cost basis and uncertainty. A positive intercept may be useful performance evidence under those conditions. It does not, by itself, identify why the strategy worked, prove a manager caused excess performance or guarantee a future edge.

## A causal question names an action, an outcome and a counterfactual

<MCQ client:visible pretest
 question={"You want to know whether changing an order route changes cost. Which outcome belongs in that causal question?"}
 options={[{"text": "The same type of order episode’s cost under each specified route and benchmark", "correct": true}, {"text": "The asset return caused by rewriting a predictive feature column"}, {"text": "Any correlation between historical signals, regardless of action or time horizon"}]}
 explanation={"A causal contrast names the actual alternative policies and a common outcome. Portfolio wealth and underlying asset return must not be silently exchanged."}
/>

For an execution study, let $A=1$ mean a specified aggressive routing policy and $A=0$ a specified less aggressive policy for the same type of order. Let Y be execution cost in basis points against the same benchmark and horizon. These are actual alternative actions, rather than edits to a predictive spreadsheet column.

Write $Y_i(1)$ and $Y_i(0)$ for the cost that order episode i would have under each route. A **potential outcome** is the outcome under one specified action. The individual effect is $Y_i(1)-Y_i(0)$; the target population's average effect is $\mathbb E[Y(1)-Y(0)]$. Ordinary data observes the route taken and its cost, not both outcomes for the same episode. This is the counterfactual problem introduced in [Hernán and Robins, chapter 1](https://miguelhernan.org/s/hernanrobins_WhatIf_19aug26.pdf).

### Urgency can affect route choice and cost

Half the order episodes are calm and half urgent. Supply these potential costs:

Now suppose aggressive routing is chosen for 80% of urgent episodes and 20% of calm ones. In the aggressive group, 80% of episodes are urgent, so mean cost is $0.2(15)+0.8(55)=47$ bp. In the less aggressive group, 20% are urgent, so mean cost is $0.8(10)+0.2(50)=18$ bp. The observed arm difference is **29 bp**, although the supplied causal effect is **5 bp** in every episode.

<PredictionAndActionLab client:visible mode="action" labels={{"title": "Observed routing gap versus a stipulated effect", "caption": "Invented population, half calm and half urgent. Potential costs are supplied classroom truths: A=0 costs 10 or 50 basis points; A=1 adds the selected causal effect. Route selection depends on urgency. Potential-outcome columns are not jointly observed for a real episode. Zero-mass arms have no observed mean; the model truth remains stipulated even when observational standardisation is unavailable."}} />

The remaining 24 points reflect different urgency composition, not an extra effect of routing. If selection is reversed—20% aggressive among urgent, 80% among calm—the observed difference becomes $0.8(15)+0.2(55)-[0.2(10)+0.8(50)]=-19$ bp, while the effect remains +5. Confounding can inflate, reduce or reverse a contrast.

**Pitfall:** defining an effect as “hold everything else fixed” without saying what is fixed. Consequences of routing, such as queue placement and fill timing, can be part of the total effect. Holding them fixed would define a different effect. Specify policy versions, order population, benchmark and observation horizon.

### When to use it

Use a causal estimand when comparing the consequences of actual alternative actions: routing, order size, a mandate or a portfolio policy. If the outcome is portfolio wealth, state that explicitly. Do not silently switch the outcome to the asset's return and claim that a signal must cause it.

## Adjustment works under identification assumptions

<MCQ client:visible pretest
 question={"Both routing groups exist overall. Is that enough for positivity after adjusting for urgency?"}
 options={[{"text": "No: both routes need positive probability within each relevant target urgency group", "correct": true}, {"text": "Yes: one observation in each overall arm supplies every missing subgroup"}, {"text": "Yes: a sufficiently flexible regression guarantees overlap"}]}
 explanation={"At deterministic selection, aggressive urgent and less aggressive calm episodes exist but the other two arms do not. Overall group counts alone are insufficient."}
/>

A **confounder** for an action's effect is a common cause of action and outcome. In the routing model, pre-route urgency affects both. Adjustment compares routes **within urgency groups** and then uses the same target weights for both routes.

With the supplied population and both routes observed in each group, standardised mean cost under A=1 is $0.5(15)+0.5(55)=35$ bp; under A=0 it is $0.5(10)+0.5(50)=30$ bp. Their difference is five points. We have replaced the routes' different observed urgency mixes with one common target mix.

A standardisation formula is

$$
\mathbb E[Y(a)]=\sum_z\mathbb E[Y\mid A=a,Z=z]P(Z=z).
$$

This identification requires conditions, not just a regression that happens to include Z:

- **Consistency:** the observed episode outcome agrees with the potential outcome for its actual, well-defined policy. “Aggressive” must not hide incompatible versions without accounting for them.
- **Conditional exchangeability:** within pre-action Z, route selection is unrelated to the potential costs. We assume urgency captures the necessary common causes; a hidden driver can invalidate that assumption.
- **Positivity:** each route has positive probability in every urgency group represented in the target population. A structurally missing arm with zero probability cannot be learned merely by making the dataset bigger.
- **The stated interference scope:** here one episode's assigned route does not alter another's potential cost. Shared order books and concurrent orders may require a different unit and policy definition.

[Hernán’s discussion of identification conditions](https://doi.org/10.1177/0962280211398037) separates these requirements. A causal interpretation can be available from observational data under justified assumptions; observational data is not intrinsically incapable of causal inference. Randomisation can support exchangeability by design, but does not automatically solve adherence, missing outcomes, interference or transport.

<PredictionAndActionLab client:visible mode="action" selectionPercent={100} labels={{"title": "A missing arm blocks observational standardisation", "caption": "Use the same stipulated routing population. At selection probability 0% or 100%, one route is absent in each urgency group. The true effect is supplied for teaching, but standardisation from observed arms is unavailable. Showing model potential outcomes does not replace overlap, consistency or conditional exchangeability in a real study."}} />

Set aggressive routing to 100% for urgent and 0% for calm. We observe cost 55 for the aggressive urgent group and 10 for the less aggressive calm group: a 45-point difference. The other two arms are missing. Our teaching model still stipulates the true effect of five, but the displayed observational standardisation is **unavailable**. Reporting five from the table of supplied potential outcomes would use classroom information that real observational data does not contain.

**Pitfall:** interpreting a flat within-group association or a successful adjustment as proof that all confounding is gone. Exchangeability concerns unobserved potential outcomes. A pattern of observed data alone does not establish it. Correlation need not equal a causal effect even when no common cause exists; scale, nonlinearity, measurement and selection also matter.

### When to use it

Write the target population and assumptions next to the adjusted estimate. Check support and timing of controls; do not automatically control every available variable. The next lessons formalise causal graphs, mediators and selection paths.

## Selection can manufacture association without a common cause

<MCQ client:visible pretest
 question={"A random routing flag and a future market indicator are independent. Can selecting only matching flag/outcome pairs create an association?"}
 options={[{"text": "Yes: retention depends on both, so the selected sample can differ from the full population", "correct": true}, {"text": "No: independence must survive every outcome-dependent filter"}, {"text": "Yes: selection proves the flag now causes the market outcome"}]}
 explanation={"Conditioning on a common effect can induce association. The filter does not change the stipulated structural effect."}
/>

A **common effect** receives influences from two variables. Selecting on it can create association between them. This is different from adjusting for a pre-action common cause. The graph $A\to S\leftarrow Y$ names S as a **collider**; its role depends on the stated causal structure.

Take independent fair binary variables: a random routing flag $A\in\{0,1\}$ and a future market outcome indicator $Y\in\{0,1\}$. In this invented model, changing the flag has no effect on the market outcome. Each pair 00, 01, 10, 11 has population probability 1/4, so $\mathbb E[Y\mid A=1]=\mathbb E[Y\mid A=0]=1/2$.

Now keep only episodes where the flag “predicted correctly”: $S=1$ if $A=Y$. The retained sample contains only 00 and 11. Its conditional means become one for A=1 and zero for A=0: **an observed difference of one** in the binary mean (100 percentage points of probability), despite the stipulated zero causal effect. Retention depends on the future outcome, so it is unavailable as an honest arrival-time eligibility rule.

<PredictionAndActionLab client:visible mode="selection" conditioned={true} labels={{"title": "A future-dependent filter creates association", "caption": "Invented independent fair binary route flag A and future market indicator Y; neither causes the other. Each original pair has mass 25%. The chosen filter retains only A=Y, using future information; conditional sample weights are renormalised. It changes selected association, not the stipulated causal effect. A future-dependent filter is unavailable at order arrival."}} />

No common cause of A and Y was needed to generate this selected association. Conditioning on the common effect created it. The [selection chapter of What If](https://miguelhernan.org/s/hernanrobins_WhatIf_19aug26.pdf) treats common-effect selection separately from common-cause confounding. Calling every source of bias a “confounder” can lead you to choose the wrong adjustment.

### When to use it

Audit how episodes, securities and model candidates entered the sample. Eligibility based on later success, survival or realised outcomes can change what a backtest measures. A chronological split still leaks if both sides use the same future-dependent filter; an honest unfiltered holdout can reveal a predictive failure without identifying its entire causal explanation.

## Predictive stability and causal identification have separate limits

<MCQ client:visible pretest
 question={"A route effect was identified under a clear design in one venue. What follows about future venues, quantities or liquidity states?"}
 options={[{"text": "Transport needs further arguments; identification in one population does not guarantee invariance", "correct": true}, {"text": "The causal label guarantees the same effect and safe leverage everywhere"}, {"text": "The effect must reverse as soon as the regime frequency changes"}]}
 explanation={"Treatment versions, scale, interference and market conditions can change the target effect. A justified causal estimate is conditional evidence, not a durability certificate."}
/>

Return to the original proxy model. Change the deployment return equation explicitly to $Y=-0.02Z+E$, retaining the independent end shock, keeping the recorded feature rule and the same position policy. Gross policy expectation becomes

$$
\mathbb E[(X/2)Y]=\mathbb E[(Z+U)(-0.02Z+E)/2]=-0.01.
$$

After the same expected five-basis-point cost, net expectation is **−1.05%**. The structural relationship changed. The causal effect of editing the recorded feature on the asset remained zero in both versions. That absence neither guaranteed failure before the change nor protected the prediction afterwards.

<PredictionAndActionLab client:visible mode="proxy" coefficientPercent={-2} labels={{"title": "Change the return mechanism, then the regime mix", "caption": "Same one-period proxy model with independent final shock ±4%, zero-return cash and total entry-and-exit cost 10 basis points times initial |w|. Initial selected return coefficient is −2 percentage points, so expected policy P&L is negative. Changing the regime mixture is a different assumption from changing the coefficient. All eight realised outcomes remain possible with the displayed mixture; no trading guarantee is implied."}} />

A change of regime **frequency alone** need not reverse the strategy. Suppose Z=+1 now has probability 0.8 while U remains independent and balanced, but the original $Y=0.02Z+E$ relation holds. The four row masses are 0.1, 0.1, 0.4, 0.4. Conditional mean gross policy returns are still 2%, 0%, 0%, 2%, so expectation is $0.1(2\%)+0.4(2\%)=1\%$. Expected absolute exposure remains 0.5 and net expectation remains 0.95%. The underlying mean return changes to 1.2%. The mechanism and decision rule determine what transports; the label “confounded” does not predict a necessary reversal.

Likewise, an identified route effect need not be stable across a different venue, size, liquidity state, treatment version or time period. Understanding a mechanism can inform transport arguments; knowing the detailed mechanism is not a prerequisite for every identified average effect, and “causal” is not a guarantee of durability or safe leverage.

**Pitfall:** diagnosing one bad live period as proof of confounding. Chance, changed costs, leakage, implementation bugs, parameter error and distribution shift can all contribute. Purging, deflation and chronological evaluation address particular statistical or information problems; they do not supply exchangeability, but neither are they useless for detecting predictive instability.

### When to use it

For a predictive policy, monitor calibration, net outcomes, costs, exposure and shifts in the input/outcome relationship. For a causal estimate, also monitor the treatment definition, identification assumptions and target population. Neither a backtest nor a causal label removes uncertainty from the decision.
