## Numerical cases

All cases are invented. Use the stated period, currency and assumptions. Candidate amounts refer to these tables, not to a product forecast.

**Sample:** index starting weights A 50%,B 30%,C 20%; one-period total returns A +10%,B 0%,C −5%. The physical sample starts A 60%,B 40%,C 0%, with no rebalancing or costs.

**Swap:** owned basket 100 initially; basket total return 3%, index total return 8%; notional 100; separate fee 0.20. The swap exchanges basket return for index return and performs as contracted. **Exposure** uses that same end-period positive swap value before settlement, a separate fee obligation, and legally available realizable collateral 3, with no top-up, other recovery or costs.

**Fee:** fixed fund NAV 10,000; securities 5,000 lent for 90 days; simple annual gross fee 2% using 90/360; agent receives 20% of the gross fee; no other costs. Noncash collateral 5,100 is a separate protection balance.

**Stress:** securities initially 50, noncash collateral 51; security price +10%, collateral price −20%; borrower defaults with no top-up, other recovery, indemnity or costs. Stated collateral value can be realized immediately in full.

**Tracking:** three non-overlapping annual fund-minus-index total-return gaps are −1,+1,−3 percentage points. Use matching currency/dividend conventions and sample standard deviation with divisor n −1; do not annualize again.
